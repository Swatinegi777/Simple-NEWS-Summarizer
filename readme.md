# AI News Summarizer

A command-line tool that fetches the latest news on any topic and summarizes it into clear bullet points. It uses **Tavily** for live web search, **Google Gemini** for summarization, and **LangChain** to connect the pieces.

## Features

- Search the web for the latest news on any topic you enter
- Get a concise bullet-point summary generated by Gemini
- See the source URLs for every article used
- Simple LangChain pipeline (`prompt | llm | output parser`)

## How It Works

```
User topic → Tavily Search (top 5 results) → Prompt template → Gemini LLM → Bullet-point summary + Sources
```

1. You enter a topic (e.g. `AI`, `cricket`, `stock market`).
2. Tavily searches for `Latest <topic> news` and returns up to 5 results.
3. The results are passed into a prompt that asks Gemini to summarize them in bullet points.
4. The summary is printed, followed by the list of source links.

## Tech Stack

- Python 3.9+
- LangChain (`langchain-core`, `langchain-community`)
- Google Gemini via `langchain-google-genai`
- Tavily Search API
- python-dotenv

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Swatinegi777/Simple-NEWS-Summarizer.git
cd Simple-NEWS-Summarizer
```

### 2. Install dependencies

```bash
pip install langchain langchain-core langchain-community langchain-google-genai tavily-python python-dotenv
```

### 3. Set up API keys

Create a `.env` file in the project root:

```env
TAVILY_API_KEY=your_tavily_api_key
GOOGLE_API_KEY=your_google_gemini_api_key
```

- Tavily key: https://tavily.com
- Gemini key: https://aistudio.google.com

> Never commit your `.env` file. Add it to `.gitignore`.

### 4. Run

```bash
python newssumarizer.py
```
